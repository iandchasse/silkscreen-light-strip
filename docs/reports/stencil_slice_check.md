**Overrides on the stock "0.12mm Fine @Elegoo CC2 0.4 nozzle" process:** `layer_height` = 0.1, `initial_layer_print_height` = 0.1, `elefant_foot_compensation` = 0, `brim_type` = no_brim, `brim_width` = 0, `enable_support` = 0, `ironing_type` = no ironing, `enable_arc_fitting` = 0, `slow_down_layers` = 2, `initial_layer_speed` = 30.

**Elephant-foot compensation (info only):** with the stock value 0.1 instead of 0, the slicer opens every layer-1 (squeegee side) aperture by +0.100 mm (across) and +0.100 mm (along) per side. That is the wrong taper for paste release and puts down more paste, so the process must have it at 0.

Method: apertures are tested by sweeping every extrusion segment by its `;WIDTH` and intersecting with the aperture rectangle (squeegee size on layer 1, pad size on layer 2); the part is placed at the bed centre by this script (with Orca's own arrange it turned the card by 90 degrees) and its position is then read from the centre of the first layer's extrusion bounding box (Orca moved it 1.5 mm in y from where it was put), so the read-back does not depend on where Orca puts it. The pocket is tested against its outline shrunk by 0.05 mm. "Floating" is extrusion further than 0.25 mm from any bead of the layer below (bead ends and corners overhang by up to about 0.2 mm without being a problem). Failing lines are `Support`, `Bridge`, `Ironing`, `Overhang wall` and any G2/G3 arc outside the end G-code.
